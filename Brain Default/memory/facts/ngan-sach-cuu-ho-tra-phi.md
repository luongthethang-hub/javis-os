# Ngân sách trợ giúp khi tự sửa thất bại
Chủ giới hạn API trợ giúp trả phí ở 3.000 token/ngày cho thiết kế cứu hộ. Khi không tự sửa được, ưu tiên Antigravity rồi Claude Desktop trước khi dùng API trả phí.

**Vì sao:** Giới hạn chi phí tìm trợ giúp bên ngoài.

**Áp dụng:** Đây là giới hạn thiết kế, không phải xác nhận đã triển khai bộ đếm, cài dịch vụ hay cấp quyền sửa hệ thống.
